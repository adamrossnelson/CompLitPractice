Windows Command-Line Walkthrough Extended

This is a self-paced, ~2.5 hour hands-on walkthrough for Windows users. Work through the parts in order. Later parts assume you have done the earlier ones.

Open the Anaconda PowerShell Prompt now before reading further: click the Start menu, begin typing Anaconda PowerShell, and press Enter when you see Anaconda PowerShell Prompt. A window with a text prompt appears. That is where you will type every command in this guide.

Use the Anaconda PowerShell Prompt, not any of the other terminals

Windows comes with several different terminal programs, and they behave differently. You may have seen or heard of:

  • Anaconda PowerShell Prompt — a PowerShell window that has Python and the conda tool ready to use. This is the one you should use for this guide.
  • Anaconda Prompt — installed right next to it, with a nearly identical name. It also has Python and conda ready to use, but it is built on the older Command Prompt, and many commands in this guide will not work there.
  • Command Prompt (cmd.exe) — the classic Windows command line.
  • PowerShell — a plain PowerShell window, without Python and conda preconfigured.
  • Windows Terminal — a modern window that can host any of the above.
  • Git Bash — a Unix-style shell installed alongside Git.

PowerShell shares many command names with the Mac terminal (pwd, ls, cd, mv, cp, rm, cat). That makes it easier to follow along with classmates who use Macs.

When this guide says “at the prompt” or “in the terminal,” always use the Anaconda PowerShell Prompt.

What is a “prompt”?

The prompt is the short bit of text the terminal shows when it is waiting for you to type your next command. In Anaconda PowerShell Prompt, it typically looks something like (base) PS C:\Users\yourname>. The (base) at the start is telling you which conda environment is active; the PS tells you that you are in PowerShell; the C:\Users\yourname is your current directory; the > character marks the end of the prompt. If you do not see PS in your prompt, you have opened the wrong program. Close it and open Anaconda PowerShell Prompt instead. Whenever this guide says “at the prompt,” it means: type this command into the Anaconda PowerShell Prompt window, then press Enter.

Vocabulary as we go

Words like directory, parent, child, alias, ~, and absolute path get introduced in short callouts the first time they appear. Do not skip the callouts. The callouts are an important component of this walkthrough.

Part 1 — Getting oriented

1.1 Where am I?

Type this exactly and press Enter:

pwd

pwd stands for “print working directory.” It prints the current directory. The current working directory is the folder the terminal considers “where you are right now.” Every command you type looks at that folder first, unless you tell it to look somewhere else.

You will see a short table with the heading Path, and underneath it something like C:\Users\yourname. That is your home directory.

Folder = directory

“Folder” is the word File Explorer uses. “Directory” is the word programmers use. They mean exactly the same thing. This guide uses “directory” from here on.

What ~ means

~ (tilde) is PowerShell’s shortcut for your home directory. On most Windows machines your home directory is C:\Users\yourname. Anywhere in a command that you could type your full home path, you can instead type ~ and PowerShell will substitute the real value for you. So ~\Desktop and C:\Users\yourname\Desktop refer to exactly the same folder. Every user account on the machine has its own ~.

You may also see $HOME or $env:USERPROFILE in instructions you find online. In PowerShell, these usually hold the same path as ~. The %USERPROFILE% spelling you may find in older Windows instructions belongs to Command Prompt and Anaconda Prompt. It does not work in PowerShell.

1.2 What is in here?

ls

ls lists the contents of the current directory. You will see Desktop, Documents, Downloads, and so on, in a table with four columns. Mode describes each item (a d marks a directory). LastWriteTime shows when it was last modified. Length shows its size in bytes, and is left blank for directories. Name is the item’s name.

What is an “alias”?

PowerShell’s own commands have longer names built from a verb and a noun, joined by a hyphen: Get-Location, Get-ChildItem, Move-Item. To make life easier for people coming from other terminals, PowerShell also provides aliases. An alias is a short nickname that stands in for a full command. pwd is an alias for Get-Location, and ls is an alias for Get-ChildItem. (dir is another alias for Get-ChildItem.) To see what any alias stands for, run:

Get-Alias ls

Aliases give you the same names as the Mac and Linux commands, but not the same flags. A Mac command like ls -lhra produces an error here. This guide shows you the PowerShell flags that do the same jobs.

1.3 The ls flag worth memorizing

Try:

ls -Force

Memorize that combination — ls -Force. The -Force flag tells ls to list all files, including hidden ones (files whose names would ordinarily be kept out of view).

Other flags worth knowing:

  • ls -Force — show all files, including hidden ones
  • ls -Recurse — also list the contents of every subdirectory
  • ls -File or ls -Directory — show only files, or only directories
  • ls | Sort-Object LastWriteTime — order the listing by modification date (oldest first)
  • ls | Sort-Object LastWriteTime -Descending — order by modification date, newest first
  • ls | more — pause after each screenful (useful for long listings)
What is a “flag”?

A flag (also sometimes called an option, a switch, or in PowerShell a parameter) is a short modifier you add after a command to change how that command behaves. In PowerShell, flags begin with a hyphen and are usually whole words: -Force, -Recurse, -File. They are not case-sensitive, so -force works too. You can shorten a flag, as long as the shortened version could not be mistaken for a different flag. This means -Rec works for -Recurse. Unlike on Mac and Linux, you cannot smoosh several flags together behind one hyphen the way -lhra does. (In Command Prompt and Anaconda Prompt, flags begin with a forward slash instead, as in /a. Those do not work here.)

What is a “pipe”?

The | character (on most keyboards, Shift plus the backslash key) is called a pipe. It sends the output of the command on its left into the command on its right. In ls | Sort-Object LastWriteTime, ls produces a listing, and the pipe hands that listing to Sort-Object, which puts it in order. You will use pipes again in Parts 4 and 6.

Hidden files

Windows marks some files and directories with a hidden attribute, which keeps them out of the default ls listing. ls -Force shows them, with an h in the Mode column. Files whose names start with a dot, such as .gitconfig, are hidden by convention on Mac and Linux. Windows does not hide them automatically, so you may see them even in a plain ls.

Try it: what hidden files are in your home directory?

Run ls -Force ~ and read the Name column. Items with an h in the Mode column, such as AppData, are hidden. You may also see oddly named entries such as Application Data or My Documents. These are compatibility links left over from older versions of Windows. You may also see items such as .conda, .jupyter, and .ipython. These are configuration and system files. Leave the hidden configuration files alone for now, but know they exist.

1.4 Moving around: cd

cd stands for “change directory.” Try each of these, one at a time, running pwd after each so you can see which directory you end up in:

cd ~\Desktop
pwd
cd ..
pwd
cd ~
pwd

What each did:

  • cd ~\Desktop — go to your Desktop.
  • cd .. — go up one level to the parent directory. .. always means “the parent of where I am.”
  • cd ~ — go to your home directory.
If cd ~\Desktop does not work

On many Windows computers, OneDrive stores the Desktop at ~\OneDrive\Desktop instead of ~\Desktop. If cd ~\Desktop reports that it cannot find the path, or if files you save to ~\Desktop never appear on your actual desktop, try cd ~\OneDrive\Desktop. If that works, use ~\OneDrive\Desktop everywhere this guide says ~\Desktop.

What is an “argument”?

An argument is an extra word you type after a command to tell it what to act on. In cd ~\Desktop, the string ~\Desktop is the argument (a path argument to be more specific). In this case the path argument tells cd where to go. In ls -Force ~, the flag -Force and the path ~ are both arguments. Some commands take no arguments at all; some accept several; some have optional arguments and behave in a default way when none is given (as ls alone falls back to listing your current directory).

Parent, child, sibling

Directories form a tree. If Desktop lives inside C:\Users\jsmith, then C:\Users\jsmith is the parent of Desktop, and Desktop is a child of C:\Users\jsmith. Two directories that share the same parent (Desktop and Downloads, for example) are siblings.

What is a “path”?

A path is the address of a file or a directory on your computer. The sequence of directory names, separated by backslashes (\) on Windows, that tells the system exactly where to find that item. C:\Users\jsmith\Desktop\notes.txt is a path; so is drafts\readme.txt; so is ... Almost every command that touches a file or folder takes a path as one of its arguments.

Absolute vs. relative paths
  • An absolute path starts with a drive letter and a backslash (C:\..., D:\...) or with ~.
  • A relative path does not start with a drive letter or ~. It is understood in terms of your current working directory.

When a command “cannot find” a file, the most common reason is confusing relative and absolute paths.

Slashes: \ versus /

On Windows, paths use the backslash \ between directory names. On macOS and Linux, they use the forward slash /. PowerShell is forgiving (it will usually accept either), but every example in this guide uses \ to match Windows conventions.

1.5 Tab completion — the most useful shortcut

Type cd ~\Doc and then, before pressing Enter, press the Tab key. The terminal will complete it to your Documents directory for you. (PowerShell may also spell out ~ as your full home path, such as C:\Users\yourname\Documents. That is the same place.)

If there are multiple matches (e.g., Documents and Downloads both start with Do), pressing Tab repeatedly will cycle through the possibilities. Type another letter or two to narrow the choices, then Tab again.

PowerShell can also complete command names and flags. Type Get-Ali and press Tab, or type ls -Fo and press Tab.

Use Tab constantly. It prevents typos, and it is a check on reality: if Tab will not complete a name, that name does not exist where you think it does.

1.6 Set up your practice folder

You will do all the rest of this walkthrough inside a dedicated practice folder so that early mistakes do not disturb anything else on your computer.

Challenge: create ~\Projects\computer-literacy and cd into it. Two commands. Try to write them yourself before revealing. 
mkdir ~\Projects\computer-literacy
cd ~\Projects\computer-literacy

mkdir = “make directory.” In PowerShell, mkdir will automatically create any missing parent directories along the way (so if ~\Projects does not exist yet, mkdir makes it too). If the directory already exists, PowerShell prints a red error message saying so. That error is harmless.

Confirm you are in the right place:

pwd

You should see C:\Users\yourname\Projects\computer-literacy.

Part 2 — Making, moving, renaming, deleting

You are inside ~\Projects\computer-literacy. Everything from here happens in this folder unless stated otherwise. If you ever get lost, run cd ~\Projects\computer-literacy to return to the practice folder.

2.1 Create an empty file

There is no touch command in PowerShell. Instead, use New-Item:

New-Item notes.txt -ItemType File
ls

New-Item creates new things. The -ItemType File flag tells it to make a file, rather than a directory. PowerShell prints a short table describing the new file. The result is a zero-byte file with the name you asked for.

File extensions

The .txt at the end is a file extension. Extensions are naming conventions — the operating system looks at the extension to guess what kind of file it is and which program should open it. They are not magic: notes.txt, notes.csv, and notes are all just files with different names. But the convention matters, because tools (and humans) read the extension to decide what to expect. You will encounter .txt, .csv, .md, .qmd, .ipynb, .py, and .html in this guide.

2.2 Rename with mv

mv notes.txt readme.txt
ls

mv means “move,” but move and rename are (essentially) the same operation. Both moving and renaming a file involve changing the file’s path, which may involve changing its name, its location, or both. (mv is an alias for Move-Item. PowerShell also has ren, an alias for Rename-Item, which only renames.)

2.3 Move into a child directory with mv

Challenge: create a drafts folder and move readme.txt into it 
mkdir drafts
mv readme.txt drafts\
ls
ls drafts

After this, readme.txt should appear inside drafts\ and not in the current directory. The trailing \ on drafts\ is not required, but it signals “this is a folder” to your future self reading the command.

Idea: watch the changes happen in File Explorer

Open File Explorer alongside your Anaconda PowerShell Prompt and navigate to ~\Projects\computer-literacy. You can also run ii . at the prompt, which opens the current directory in File Explorer. (ii is an alias for Invoke-Item, and . means the current directory, as you will see in 2.4.) As you run mv, mkdir, rm, and so on at the prompt, refresh File Explorer (press F5) to watch the same files appear, disappear, and change places. Seeing the command line and the point-and-click interface act on the same folder is one of the fastest ways to build a durable mental model.

2.4 Move a file from a child back to the current directory

Challenge: move readme.txt from drafts\ back to where you are now 
mv drafts\readme.txt .
ls

The . is not a typo. . means “the current directory.” So mv drafts\readme.txt . means “move the file drafts\readme.txt into the directory .” (that is, into wherever you are now).

2.5 Move a file up to the parent

Challenge: move readme.txt up to ~\Projects, then back 
mv readme.txt ..
ls
ls ..
mv ..\readme.txt .
ls

.. means “the parent directory,” so mv readme.txt .. moves the file up one level. Then mv ..\readme.txt . brings it back.

2.6 Copy with cp

For a single file:

cp readme.txt readme-backup.txt
ls

For a directory (which contains other files, and possibly other directories inside it), add the -Recurse flag, because copying a folder means copying everything inside it too:

cp -Recurse drafts drafts-backup
ls

cp is an alias for Copy-Item. Without -Recurse, cp copies only the folder itself and leaves its contents behind.

Part 3 — Editing text with Notepad

Windows does not include the nano editor that Mac and Linux users often rely on. Instead, we will use Notepad, which ships with every copy of Windows and can be launched directly from the Anaconda PowerShell Prompt. Open your readme.txt:

notepad readme.txt

A separate Notepad window appears. The Anaconda PowerShell Prompt hands off control to Notepad but does not freeze. You can even keep typing commands in the prompt while Notepad is open (though it is cleaner to finish editing first).

Type these exact lines into Notepad (you can copy them from your browser and paste with Ctrl + V):

Computer Literacy Practice
==========================
This is my practice readme.

TODO: add a list of my favorite CLI commands
TODO: try Select-String on this file later

Save the file with Ctrl + S.

To close the Notepad window press Alt + F4 or click the red X.

Now verify what you wrote and saved is there in readme.txt:

cat readme.txt

cat prints a file’s contents to the terminal. It is great for short files. Do not cat a huge file. It will flood your terminal with output. Instead consider using more, Get-Content -Head, or Get-Content -Tail to view parts of the file.

  • more will let you scroll through a file page by page.
  • Get-Content file -Head N will show you just the first N lines of a file.
  • Get-Content file -Tail N will show you just the last N lines of a file.
What does “concatenate” mean?

cat is short for concatenate. On Mac and Linux, cat is a program that was originally designed to join several files together and print the joined result. In PowerShell, cat is an alias for Get-Content, which reads files. To concatenate two or more things is to join them end-to-end into a single, longer thing. The word comes from the Latin catena, meaning “chain.” So concatenation is, literally, chaining things together. In computing you will meet the word most often in two places: (1) in the Mac/Linux cat command; and (2) in almost every programming language, where “string concatenation” means gluing two pieces of text together (for example, joining "Hello, " and "world" to produce "Hello, world").

The TODO: lines are on purpose

You just added two TODO markers to your file. You will search for them with Select-String in Part 6. Developers leave TODO notes throughout their code as reminders, and being able to find those markers across an entire project is a genuinely useful skill.

Part 4 — Downloading and previewing real data

You will download three CSV files, then practice looking at them without opening a spreadsheet.

One setup line before you work with data files

Run this line once now, exactly as written:

$PSDefaultParameterValues['*:Encoding'] = 'utf8'

It tells PowerShell to use UTF-8 whenever a command reads or writes a text file. UTF-8 is the standard text encoding that Excel, Python, R, and Macs all expect. Without this line, the Windows PowerShell inside Anaconda PowerShell Prompt reads and writes some text files in older formats. The CSV excerpts you make in Part 5 could then open incorrectly in Excel.

In the line itself, $PSDefaultParameterValues is a PowerShell setting that stores default values for flags. '*:Encoding' means “the -Encoding flag of every command.” 'utf8' is the value to use. The setting lasts only until you close the window. Run it again each time you open a new Anaconda PowerShell Prompt before working with data files.

What is “encoding”?

A computer stores text as numbers. An encoding is the agreed-upon scheme for translating characters into those numbers and back again. When a file is written in one encoding and read in another, the result is garbled text. For a CSV, the result can be a spreadsheet that crams each whole row into a single column. UTF-8 is the most widely used encoding in the world today, and it is the safe choice for data files.

4.1 Make a data\ folder and go into it

mkdir data
cd data
pwd

4.2 Download files with curl.exe

Modern versions of Windows include curl as a built-in program. curl -O downloads a file from a URL and saves it using the filename from the URL. In the Anaconda PowerShell Prompt, type it as curl.exe. Run these three commands (each is one long line):

curl.exe -O https://raw.githubusercontent.com/adamrossnelson/confident/refs/heads/main/data/complaints-bank.csv
curl.exe -O https://raw.githubusercontent.com/adamrossnelson/confident/refs/heads/main/data/mpg_excerpt.csv
curl.exe -O https://raw.githubusercontent.com/adamrossnelson/confident/refs/heads/main/data/confident_fictional_books.csv
Why curl.exe and not curl?

In Windows PowerShell, curl is an alias for a different PowerShell command called Invoke-WebRequest. That command does not understand the -O flag, so plain curl -O produces an error. Typing curl.exe skips the alias and reaches the real curl program. Mac and Linux tutorials write plain curl, so watch for this whenever you copy a command from one.

4.3 See what you got

ls

You will see three CSV files listed with their sizes in bytes in the Length column. Which of the three CSVs is largest?

4.4 Peek at contents — the right way

What is a CSV file?

CSV stands for comma-separated values. It is the simplest, most portable format for tabular data. Tabular data is data that is arranged in rows and columns, the way you would lay it out in a spreadsheet or a printed table. Each row is one observation or record (one respondent in a survey, one transaction in a bank ledger, one book in a library catalog); each column is one variable or field (that respondent’s age, the transaction’s amount, the book’s title). Inside the file itself, each line is one row, and the values within a row are separated by commas. The very first line of a CSV is usually a header listing the column names.

CSVs are everywhere in data science because they are plain text (so any program on any system can read them), lightweight (they store nothing but the data itself such as no fonts, no colors, no formulas), and language-agnostic (Python, R, Excel, and even a plain text editor can all open the same file). When you download data from a government open-data site, a research repository, or an API, it very often arrives as a CSV.

What does “portable” mean?

When programmers describe a file format, a program, or a piece of code as portable, they mean that it works well across many different systems and situations. Similar to the way a paperback book is portable in the everyday sense of “you can take it anywhere.” A portable file format opens on a Mac, a Windows PC, a Linux server, and a Chromebook, in software written by many different companies, without needing conversion. Plain-text formats such as CSV, JSON, and Markdown are among the most portable formats in existence, which is a large part of why they have endured for decades.

What is an API?

API stands for application programming interface. In broad terms, an API is a well-defined set of rules that lets one piece of software request information or services from another. Weather services, government statistics offices, universities, and social-media platforms all publish APIs that researchers use to gather data. You are not expected to use an API in this walkthrough; the term appears here only because CSVs are one of the most common formats that APIs return.

Do not cat complaints-bank.csv. This is a big file and it will fill your terminal with noise. Instead, look at the first several lines:

Get-Content confident_fictional_books.csv -Head 10

That shows the first 10 lines. Change 10 to 5 to see only the first five:

Get-Content confident_fictional_books.csv -Head 5
Get-Content is PowerShell’s file reader

Get-Content reads a file one line at a time. On its own, it prints the whole file. In fact, cat is an alias for Get-Content. The -Head flag tells it to stop after the first however-many lines, which makes it PowerShell’s version of the Mac head command. Its partner, -Tail, shows the last lines instead. Older instructions sometimes write -TotalCount instead of -Head. The two flags do the same thing.

For scrolling through a larger file, use more:

more complaints-bank.csv

You are now “inside” more. Press the space bar to advance one screen at a time. Press q to quit. Getting stuck inside more is a common frustration for beginners… (remember q to exit).

When a program takes over your prompt

Some commands hand control over to a program (Notepad opens in its own window; more, quarto preview, jupyter lab, and running Python servers stay inside the terminal). Your normal terminal prompt disappears until you exit the program. If you ever feel stuck: try q (for more), close the window (for Notepad), or press Control + C (which sends a stop request to most other running programs).

4.5 Count rows

Why count rows from the command line?

A row count is the fastest possible answer to a basic data-science question: how many observations (records) does this dataset have? Before you open a file in Python, R, or a spreadsheet, a one-line command tells you in a fraction of a second whether you are looking at 50 rows, 50 thousand, or 50 million. That number changes what you will do next: whether it is safe to open the whole file at once in a program, whether you should take a smaller sample first, and whether the file actually contains what someone told you it did. Getting used to inspecting data at the terminal (sizes, row counts, first few lines) before jumping into a full analysis is a habit that separates confident scientists from frustrated scientists.

In PowerShell, you count lines by reading the file with Get-Content and asking how many lines came back:

(Get-Content complaints-bank.csv).Count

The parentheses tell PowerShell to finish reading the file first. .Count then reports how many lines it read. So the whole line reports the total number of lines in the file.

That first line is the CSV header, so the number of data rows is one less than what PowerShell reports.

Try looking at all three CSVs at once using a wildcard:

ls *.csv

The * matches any characters, so *.csv matches every file in the current directory ending in .csv. To count the lines in each of those files, pipe the list into ForEach-Object, which runs a small piece of code once for each file:

ls *.csv | ForEach-Object { $_.Name; (Get-Content $_.FullName).Count }

Inside the curly braces, $_ means “the file currently being handled.” For each file, PowerShell prints the file’s name and then its line count. You do not need to memorize this line yet. Just notice how the wildcard and the pipe work together.

Wildcards are powerful and dangerous when combined with rm. Be extra careful whenever you combine * with a deleting command.

Wildcards are powerful + dangerous

The * wildcard can match any sequence of characters.

For example, to find all .csv files on your desktop from any location on your computer enter: ls ~\Desktop\*.csv

To find all files that contain the word “report” in your downloads from any location on your computer enter: ls ~\Downloads\*report*.*

While useful for batch operations, it can also lead to unintended consequences if used carelessly. Always double-check your commands before executing them.

Part 5 — Redirection: saving output to a file

Very often you want to save what a command prints, rather than just look at it. That is called redirection.

Did you run the setup line?

The redirection in this part depends on the setup line from the start of Part 4. If you have opened a new Anaconda PowerShell Prompt since then, run it again now:

$PSDefaultParameterValues['*:Encoding'] = 'utf8'

5.1 The > operator

Get-Content complaints-bank.csv -Head 20 > ~\Desktop\complaints-sample.csv

Read that out loud: “Take the first 20 lines of complaints-bank.csv, and instead of printing them to the terminal, redirect them into a new file called complaints-sample.csv on my Desktop.”

Now open your Desktop in File Explorer (or run ii ~\Desktop). After running the Get-Content command suggested above, you will see a small CSV file there. Double-click it to open in Excel. This is a very common real-world workflow: make a small excerpt of a big data file so you can inspect it quickly.

Why the setup line matters here

In the Windows PowerShell inside Anaconda PowerShell Prompt, > normally writes files in an encoding called UTF-16. Excel may display a UTF-16 CSV with each whole row crammed into a single column. The setup line switches > to UTF-8, so the excerpt opens as a proper spreadsheet.

> overwrites without warning

If ~\Desktop\complaints-sample.csv already existed, > would replace it without asking. There is no “are you sure?” prompt. If you want to append to a file instead of overwriting it, use >> (two greater-than signs).

5.2 Try >>

Get-Content mpg_excerpt.csv -Head 3 >> ~\Desktop\complaints-sample.csv
cat ~\Desktop\complaints-sample.csv

You just appended a few rows of a different CSV onto the end of the sample file. (In real work you would only append data that has the same columns… but the mechanics are worth seeing.)

Part 6 — Searching with Select-String

Select-String searches for text inside files. It is PowerShell’s equivalent of the Unix grep command, and it is one of the most useful text-searching tools on Windows. Its short alias is sls.

Go back up to your practice folder:

cd ~\Projects\computer-literacy
pwd

6.1 Search in a single file

You added TODO: markers to readme.txt back in Part 3. Find them:

Select-String TODO readme.txt

Select-String prints every line in readme.txt that contains the string TODO. Unlike grep on a Mac, it automatically starts each match with the file name and the line number, in the form readme.txt:5:TODO: add a list.... The alias sls runs the same search with less typing:

sls TODO readme.txt

6.2 Make a Python file with more TODOs

Now let us give Select-String a more realistic file to search through. Create a Python file with Notepad:

notepad cleanup.py

If Notepad asks whether you want to create a new file, click Yes. Type or paste in the following (this uses only Python’s built-in features. You do not need to install anything, and you do not need to run it; you are just going to search it):

# cleanup.py — a small script for tidying up a text file

import os
import sys

# TODO: accept the input filename as a command-line argument
INPUT_FILE = "notes.txt"
OUTPUT_FILE = "notes-clean.txt"


def strip_blank_lines(lines):
    """Return only the non-empty lines."""
    return [line for line in lines if line.strip() != ""]


def lowercase_all(lines):
    # TODO: preserve proper nouns instead of lowercasing everything
    return [line.lower() for line in lines]


def main():
    if not os.path.exists(INPUT_FILE):
        print(f"No such file: {INPUT_FILE}")
        sys.exit(1)

    with open(INPUT_FILE) as f:
        lines = f.readlines()

    lines = strip_blank_lines(lines)
    lines = lowercase_all(lines)

    # TODO: also remove duplicate lines before writing out
    with open(OUTPUT_FILE, "w") as f:
        f.writelines(lines)

    print(f"Wrote {len(lines)} lines to {OUTPUT_FILE}")
    # TODO: report how many blank lines were removed


if __name__ == "__main__":
    main()

Save with Ctrl + S and close the Notepad window.

6.3 Find all TODOs in one file

Select-String TODO cleanup.py

You should see four TODO lines with their line numbers.

6.4 Find TODOs across every file in the folder

Challenge: search across every file in the current folder and all its subfolders 
ls -Recurse -File | Select-String TODO
  • ls -Recurse lists every file in the current directory (and in every subdirectory under it).
  • -File leaves the directories themselves out of the list, so only files get searched.
  • | is the pipe. It hands that list of files to Select-String.
  • Select-String TODO searches each file and reports every match, with its file name and line number.

You should see hits from both readme.txt and cleanup.py. This is how you find every leftover TODO in a project.

6.5 Case-sensitive search

On a Mac, grep pays attention to capital letters unless you tell it not to. Select-String works the other way around. It ignores capitalization by default. Compare these two commands:

ls -Recurse -File | Select-String todo
ls -Recurse -File | Select-String todo -CaseSensitive

The first command finds TODO, Todo, and todo all at once. The second adds -CaseSensitive, so it matches only the exact lowercase todo. Your files contain only uppercase TODO, so the second command finds nothing.

Part 7 — Multiple terminal sessions and local web servers

Some commands take over your prompt and do not give it back until you stop them. This is normal, and it is why programmers who use the terminal often keep two or three Anaconda PowerShell Prompt windows open at once.

7.1 Open a second Anaconda PowerShell Prompt window

Return to the Start menu and open Anaconda PowerShell Prompt a second time, so that you now have two Anaconda PowerShell Prompt windows on your screen at once. Each one is an independent terminal session, and each has its own current working directory.

Confirm this:

  • In the new window, run pwd. It will probably say C:\Users\yourname. A newly opened Anaconda PowerShell Prompt always starts at your home directory.
  • In the old window, run pwd. It should show wherever you last navigated to.

Two windows, two directories, one machine. Files you create in one are immediately visible from the other.

7.2 Start a mini web server

In your original Anaconda PowerShell Prompt, make sure you are in the practice folder, then run:

cd ~\Projects\computer-literacy
python -m http.server 8000

You will see something like Serving HTTP on :: port 8000. Your prompt is gone. Python is now running a small web server that makes the files in this folder available to a web browser on your own computer.

Open a web browser and go to http://localhost:8000. You will see a listing of your practice folder — click readme.txt to view it, click into data/ to see the CSVs, and so on.

What is localhost?

localhost (also written as 127.0.0.1) is a special network name that always means “this same computer.” When a program serves at localhost:8000, it is only reachable from your own machine — nobody on the internet can see it. That is why local previews are safe: they are visible only to you.

In practice python -m http.server 8000 is not common for data scientists. However, quarto preview and jupyter lab (both commonly used by data scientists) behave similarly.

The first time you start a Python web server on Windows, the Windows Firewall may pop up a dialog asking whether to allow Python to accept network connections. Since we are only using localhost, you can safely dismiss it in either direction. The local preview will work regardless.

7.3 Why the second terminal matters

Your first Anaconda PowerShell Prompt is “busy” running the web server. If you want to keep working. To use common commands including ls, cd, or to edit files you need the second Anaconda PowerShell Prompt window you opened in 7.1. Try it: switch to the second window and run ls in the practice folder. It works, because that terminal session is independent of the one running the server.

7.4 Stopping the server

Switch back to the terminal running the server and press Control + C. The server stops, and your prompt returns. Control + C sends a stop request. It is the standard way to tell a running command-line program to stop.

The same pattern applies to quarto preview and jupyter lab

When you run quarto preview on a Quarto project (like the site you are reading right now), or jupyter lab / jupyter notebook to open notebooks, those tools also start a local web server. Same idea: the terminal becomes busy, you open a second terminal for other work, and you use Control + C to shut the server down when you are done.

Part 8 — Three flavors of notebook

A notebook (either Quarto or Jupyter) is a document that mixes prose, code, and code output (numbers, tables, plots) in one file. Three tools you are likely to meet in a graduate-level data-science setting are Jupyter Notebook, JupyterLab, and Quarto. You do not need to install or open any of them in this walkthrough; the goal of this section is to give you enough vocabulary that you will recognize each one when you meet it in a later course or on a colleague’s screen.

8.1 Jupyter Notebook (classic)

  • File extension: .ipynb
  • How you open it: run jupyter notebook in an Anaconda PowerShell Prompt; a browser tab opens with an empty notebook ready to edit.
Jupyter Notebook vs JupyterLab

Jupyter Notebook (the “classic” interface) and JupyterLab are two different ways to use the same underlying notebook system.

In practice it is now less common to use jupyter notebook. Instead focus your efforts on learning jupyter lab.

8.2 JupyterLab

  • File extension: still .ipynb (same file format as classic Jupyter).
  • How you open it: run jupyter lab in an Anaconda PowerShell Prompt.
  • Feels: more modern, IDE-like layout. File browser on the left, tabs across the top, and the ability to open several notebooks and terminals side by side. The same notebook file, in a nicer environment.
What is an IDE?

IDE stands for Integrated Development Environment. It is a single application that bundles together the several tools a programmer typically needs such as a text editor for writing code, a file browser for navigating a project, a terminal for running commands, a debugger for inspecting a running program, and often more.

Popular IDEs you may encounter include Devin, Cursor, Visual Studio Code, PyCharm, RStudio, and Spyder (which itself ships with Anaconda). JupyterLab is described as IDE-like because, although it is really a notebook interface, it borrows the multi-panel, tabbed layout that IDEs use.

8.3 Quarto notebooks

  • File extension: .qmd
  • How you open it: any text editor. To render it into a webpage or PDF, run quarto render or quarto preview in an Anaconda PowerShell Prompt. During editing and building quarto preview is the superior choice because it gives you a live preview of your edits.
  • Feel: plain text consisting of Markdown prose interleaved with code blocks. The website you are reading right now is built from .qmd files.

What are “code fences”?

In Markdown, a code fence is a line of three backtick characters (```) that marks the beginning or end of a block of code. Anything between an opening fence and a closing fence is treated as literal code — rendered in a monospaced font, not interpreted as prose, and (in Quarto and similar tools) sometimes actually executed as a program. You can also write the language name after the opening fence, as in ```python or ```powershell, so that the code is displayed with the correct syntax highlighting. Every code example in this walkthrough is written between a pair of code fences.

Common gotchas

  • rm has no undo, and no Recycle Bin. Read every deletion command twice.
  • > overwrites without warning. Use >> to append.
  • Run the setup line in every new window before redirecting data. Without $PSDefaultParameterValues['*:Encoding'] = 'utf8', files you make with > and >> may open garbled in Excel.
  • Mac names, PowerShell flags. ls, cp, and rm work, but Mac flags like ls -lhra and rm -rf do not. Use ls -Force and rm -Recurse.
  • Type curl.exe, not curl. Plain curl is an alias for a different command.
  • ~ is different for each user. It always points at your home. PowerShell commands understand ~, but some outside programs do not. If a program like curl.exe cannot find a path that starts with ~, use $HOME instead.
  • %USERPROFILE% does not work here. That spelling belongs to Command Prompt and Anaconda Prompt. Use ~ instead.
  • Relative paths depend on where you are. When something “cannot be found,” run pwd and check.
  • Tab-complete constantly. If Tab will not complete a name, that thing is not there.
  • mv will not overwrite an existing file. On a Mac, mv silently replaces a file that already has the target name. PowerShell stops with an error instead.
  • Select-String ignores capitalization by default. Add -CaseSensitive when case matters.
  • Backslashes and forward slashes are not always interchangeable. Use \ in Windows paths to be safe.
  • Filenames with spaces need quotes: mv "My File.txt" backup\. Better still, avoid spaces in filenames you will handle from the command line.
  • Some commands take over your prompt. Ways to get unstuck: q (for more), close the window (for Notepad), Control + C (for most other running programs).
  • Anaconda PowerShell Prompt is not Anaconda Prompt. Check for PS in your prompt. Command Prompt instructions you find online, such as dir /a or type nul > file, do not work here.

Q1. In an Anaconda PowerShell Prompt, how do you print the current directory?

  • A. cd (with no argument)
  • B. pwd
  • C. dir /c
  • D. where
Answer

B. pwd stands for “print working directory.” In PowerShell it is an alias for Get-Location. Typing cd with no argument prints the current directory in the older Anaconda Prompt, but not in PowerShell.

Q2. In a filesystem tree, which of these is true about ~\Documents and ~?

  • A. They are siblings.
  • B. ~ is a child of ~\Documents.
  • C. ~\Documents is a child of ~.
  • D. They are the same directory.
Answer

C. ~\Documents lives inside ~, so ~ is the parent and ~\Documents is the child.

Q3. Which flag makes ls show hidden files as well as ordinary ones?

  • A. ls /a
  • B. ls -Force
  • C. ls -Recurse
  • D. ls -lhra
Answer

B. The -Force flag tells ls to include items that would ordinarily be kept out of the listing. ls /a is Command Prompt style, and ls -lhra is Mac style. Neither works in PowerShell. -Recurse lists the contents of subdirectories, not hidden files.

Q4. What does ~ expand to?

  • A. The root of the filesystem (C:\).
  • B. The current working directory.
  • C. Your home directory (typically C:\Users\yourname).
  • D. The Desktop.
Answer

C. ~ is PowerShell’s shortcut for the path of the current user’s home directory.

Q5. You are in C:\Users\jsmith\Projects. Which of the following is a relative path?

  • A. C:\Users\jsmith\Projects\notes.txt
  • B. ~\notes.txt
  • C. ..\notes.txt
  • D. D:\backup\notes.txt
Answer

C. Anything that does not start with a drive letter (and does not start with ~, which PowerShell replaces with an absolute path) is relative. ..\notes.txt refers to a file in the parent directory of wherever you currently are.

Q6. Which command sends you to your home directory?

  • A. cd -
  • B. cd %USERPROFILE%
  • C. cd ~
  • D. home
Answer

C. cd ~ takes you home. %USERPROFILE% is Command Prompt syntax, and PowerShell does not understand it. cd - works in the newer PowerShell 7, but not in the Windows PowerShell inside Anaconda PowerShell Prompt.

Q7. What does mkdir ~\Projects\computer-literacy do when ~\Projects does not yet exist?

  • A. It fails with an error.
  • B. It creates ~\Projects and then ~\Projects\computer-literacy in one step.
  • C. It creates only ~\Projects\computer-literacy and leaves the parent missing.
  • D. It prompts you to create the parent.
Answer

B. In PowerShell, mkdir automatically creates any missing parent directories along the way. (On Mac and Linux you need to add a -p flag for the same behavior.)

Q8. What does the Tab key do at the Anaconda PowerShell Prompt?

  • A. Inserts four spaces.
  • B. Autocompletes filenames, directory names, commands, and flags.
  • C. Runs the current command.
  • D. Switches between open windows.
Answer

B. Tab completion is the single most useful time-saving feature of the terminal. If Tab will not complete a name, that name probably does not exist where you think it does.

Q9. Which command creates an empty file called hello.txt in the current directory?

  • A. mkdir hello.txt
  • B. touch hello.txt
  • C. New-Item hello.txt -ItemType File
  • D. notepad hello.txt
Answer

C. PowerShell has no touch command. New-Item creates new items, and -ItemType File tells it to make a file rather than a directory. (mkdir hello.txt would make a directory named hello.txt.)

Q10. You have a file called draft.txt and want to rename it to final.txt. Which command works in Anaconda PowerShell Prompt?

  • A. rename draft.txt final.txt
  • B. cp draft.txt final.txt
  • C. mv draft.txt final.txt
  • D. ln draft.txt final.txt
Answer

C. mv handles both moving and renaming — renaming is just moving from one path to another in the same directory. PowerShell also offers ren, an alias for Rename-Item, which only renames. cp would leave the original in place and make a copy.

Q11. What does the . refer to in mv drafts\readme.txt .?

  • A. The parent directory.
  • B. The home directory.
  • C. The current directory.
  • D. A hidden file.
Answer

C. A single dot always means “the current directory.” So this command moves drafts\readme.txt into wherever you are right now.

Q12. What does .. mean in a path?

  • A. The current directory.
  • B. The home directory.
  • C. The parent directory.
  • D. The root of the drive.
Answer

C. Two dots always mean “the parent directory.” cd .. moves up one level.

Q13. Which command correctly copies an entire folder called drafts to a new folder called drafts-backup?

  • A. cp drafts drafts-backup
  • B. cp -Recurse drafts drafts-backup
  • C. mv drafts drafts-backup
  • D. New-Item drafts-backup
Answer

B. Copying a directory requires -Recurse, because you are copying the folder and everything inside it. Without -Recurse, cp copies only the folder itself and leaves its contents behind.

Q14. Which shortcut saves the file you are editing in Notepad?

  • A. Ctrl + O
  • B. Ctrl + W
  • C. Ctrl + S
  • D. Ctrl + X
Answer

C. Notepad uses the standard Windows save shortcut, Ctrl + S. Use Alt + F4 (or click the red X) to close the window when you are done.

Q15. When you run notepad readme.txt from the Anaconda PowerShell Prompt, what happens?

  • A. The Anaconda PowerShell Prompt freezes until Notepad is closed.

  • D. Nothing — notepad is not a valid command.

B. notepad launches the graphical Notepad application in its own window. The Anaconda PowerShell Prompt hands off control but does not block, so you could continue working there if you wanted.

Q16. Why should you avoid running cat on a large CSV file?

  • A. It will corrupt the file.
  • B. It will dump thousands of lines into your terminal all at once.
  • C. cat does not work on CSV files.
  • D. It requires a special password.

B. cat prints the entire file to the terminal. For a big file that is a flood of unreadable output. Use Get-Content file -Head N or more to look at the file, or (Get-Content file).Count for a row count, instead.

Q20. What does (Get-Content data.csv).Count report?

  • D. The file size in bytes.

C. Get-Content reads the file one line at a time, and .Count reports how many lines it read. Handy for quickly estimating how many rows are in a CSV (remember: subtract 1 for the header).

Q21. Which command downloads a file from a URL and saves it using the filename from that URL?

  • A. wget url
  • B. curl url

C. In Windows PowerShell, curl and wget are both aliases for a PowerShell command called Invoke-WebRequest, which does not understand the -O flag. Typing curl.exe reaches the real curl program. The -O flag (capital O) tells curl to save the response as a file, using the name from the URL.

Q22. What is a CSV file?

  • C. A plain-text file where each row is a line and columns are separated by commas.
  • D. A Microsoft Excel workbook.

C. “CSV” = comma-separated values. It is plain text, portable, and readable by virtually every data tool.

Q23. What does Get-Content data.csv -Head 20 > sample.csv do?

C. > is the redirection symbol: send the output that would have printed into a file. It overwrites the target without warning — no confirmation prompt.

Q24. What is the difference between > and >>?

B. Single > overwrites without warning; double >> appends onto the end of an existing file (or creates it if it does not exist).

C. ls -Recurse -File lists every file in the current folder and all folders inside it, the pipe | hands that list to Select-String, and Select-String reports each match with its file name and line number. grep is not built into Windows.
